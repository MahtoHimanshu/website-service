# Editing Rules

## Allowed edits (preferred)

- `site.config.ts` for copy, section order, and content
- `components/sections/*` when adding a new section type
- `app/page.tsx` only if adding routing/render logic

## Avoid

- Adding dependencies
- Changing build config
- Adding server-side features unless requested

## Working principles

- Make the smallest change that achieves the request.
- When unsure, update config not code.
